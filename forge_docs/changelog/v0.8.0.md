# Changelog — v0.8.0

## [0.8.0] — 2026-07-05

### Added

#### Git Plugin (`forge_plugins/git/`)
- **`models.py`**: `GitCommit`, `GitTag`, `SemverBump`, `GitHubPR`, `GitReport` dataclasses with full `to_dict` / `from_dict` serialisation.
- **`exceptions.py`**: `GitError`, `GitValidationError`, `GitOperationError`, `GitHubError` exception hierarchy.
- **`validators/git_validator.py`**: Pre-flight validation of all upstream artifacts, workspace path, git binary availability, and optional GitHub configuration.
- **`utils/git_operations.py`**: `GitOperations` — thin `subprocess` adapter for all local git commands (`init`, `config_user`, `checkout`, `add`, `commit`, `tag`, `log`, `status`, `diff`, `rev_parse`, `describe`, `is_git_repo`). All failures normalised to `GitOperationError`.
- **`utils/git_pipeline.py`**: `GitContext`, `GitPipelineStep` (ABC), and `GitPipeline` — follows the exact documentation pipeline pattern.
- **`components/branch_step.py`**: Creates and checks out `{prefix}/{project_id}` delivery branch, with fallback for pre-existing branches.
- **`components/commit_step.py`**: Stages all generated files and commits with deterministic conventional commit message. Optional LLM-enhanced messages via `llm_commit_messages: true` config flag.
- **`components/semver_step.py`**: Analyses commit log with LLM for MAJOR/MINOR/PATCH classification, falling back to rule-based conventional commit detection. Computes next version string.
- **`components/tag_step.py`**: Applies an annotated git tag from `SemverBump.recommended`. Skips gracefully when semver is unavailable.
- **`components/changelog_step.py`**: Generates and writes `CHANGELOG.md` using LLM (Keep a Changelog format) with deterministic fallback.
- **`components/github_pr_step.py`**: Creates GitHub Pull Request using `PyGithub`. Entirely config-gated (`github_enabled: false` by default). Non-fatal on any GitHub API failure.
- **`components/ci_manifest_step.py`**: Writes `ci_manifest.json` to workspace root aggregating version, branch, SHA, test status, coverage, file counts, and timestamp.
- **`prompts/`**: Four LLM prompt templates: `commit_message.txt`, `semver.txt`, `changelog.txt`, `pr_description.txt`.
- **`service.py`**: `GitService` (ABC) and `ForgeAIGit` (concrete) — 9-step orchestration matching the Documentation Plugin pattern.
- **`plugin.py`**: `GitPlugin` registers `ForgeAIGit` under `GitService` in the system registry.
- **`__init__.py`**: Package exports all public symbols.

#### Tests
- **`forge_tests/test_git.py`**: 30+ unit tests covering all components, validators, operations, pipeline, service lifecycle, plugin bootstrap, and model serialisation.

#### Infrastructure
- **`config/defaults.json`**: Added `git` configuration block with all options (branching, tagging, GitHub, commit messages).
- **`requirements.txt`**: Added `PyGithub>=2.1.1` (optional — only imported by `github_pr_step.py` when GitHub mode is enabled).
- **`forge_core/version.py`**: Bumped to `0.8.0`.
