# Changelog — v0.9.0

## [0.9.0] — 2026-07-06

### Added

#### Workflow Orchestrator (`forge_core/workflow/`)
- **`models.py`**: Declared `Workflow`, `WorkflowStage` models and `WorkflowState`, `WorkflowType` enums.
- **`exceptions.py`**: Added `WorkflowError` exceptions hierarchy including validation, execution, state, and stage sub-classes.
- **`state_machine.py`**: Implemented `WorkflowStateMachine` to govern strict state transitions.
- **`scheduler.py`**: Created `WorkflowStageScheduler` supporting custom timeouts, retry backoff delays, and synchronous thread execution.
- **`orchestrator.py`**: Created `WorkflowOrchestrator` mapping inputs and outputs between Planner, Architect, Developer, Tester, Documenter, and Git services. Supports resuming crashed/stopped flows by parsing memory logs.
- **`workflow_report.py`**: Created a report generator exporting results to `workflow_report.json` and `workflow_summary.md` on finish.
- **`service.py`**: Implemented `WorkflowService` contract and tied `ForgeAIWorkflowService` to the Kernel bootstrap lifecycle.
- **`__init__.py`**: Centralized exports.

#### Tests
- **`forge_tests/test_workflow_orchestrator.py`**: 17 comprehensive unit/integration tests achieving **97% coverage**.

#### Infrastructure
- **`forge_core/kernel/kernel.py`**: Registered `WorkflowService` in the Service Registry.
- **`launcher.py`**: Integrated Workflow status printing in console boot banner and diagnostics logs.
- **`forge_core/version.py`**: Bumped to `0.9.0`.
