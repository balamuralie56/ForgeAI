# Changelog — v0.7.0

## [0.7.0] — 2026-07-05

### Added

#### Documentation Plugin (`forge_plugins/documentation/`)
- `models.py` — `GeneratedDocFile` and `DocumentationReport` immutable dataclasses with `to_dict` / `from_dict` serialization.
- `exceptions.py` — `DocumentationError`, `DocValidationError`, `DocInferenceError`, `DocWriteError` hierarchy.
- `validators/doc_validator.py` — Input validation for `ProjectPlan`, `ArchitectureSpecification`, `ImplementationReport`, `TestReport`, and workspace path integrity.
- `utils/doc_pipeline.py` — `DocContext`, `DocPipelineStep` (ABC), and `DocPipeline` orchestrator with lifecycle event broadcasting.
- `utils/prompt_helper.py` — External prompt template loader, LLM invocation, strict JSON schema validation, and `GeneratedDocFile` mapping.
- `writers/doc_workspace_writer.py` — Atomic file writer with backup/rollback transaction support, LLM-based merge for existing files, and non-fatal `docs_manifest.json` generation.
- `prompts/` — Six external prompt templates: `project.txt`, `developer.txt`, `api.txt`, `architecture.txt`, `user.txt`, `release.txt`.
- `components/` — Seven `DocPipelineStep` sub-generators: `ProjectDocGenerator`, `DeveloperDocGenerator`, `ApiDocGenerator`, `ArchitectureDocGenerator`, `UserDocGenerator`, `ReleaseDocGenerator`, `DocSummaryGenerator`.
- `service.py` — `DocumentationService` interface and `ForgeAIDocumentation` concrete implementation orchestrating the full pipeline.
- `plugin.py` — `DocumentationPlugin` adapter registering `DocumentationService` into the system `ServiceRegistry`.
- `__init__.py` — Public package surface exposing plugin, service, models, and exceptions.

#### Tests
- `forge_tests/test_documentation.py` — 21 unit tests covering validators, pipeline context, prompt helpers, workspace writer rollbacks, manifest failures, merge strategies, service error paths, and plugin lifecycle. **93% coverage**.

#### Bug Fixes
- `forge_plugins/tester/models.py` — Added `__test__ = False` to `TestReport` dataclass to suppress pytest collection warnings.

### Changed
- `forge_core/version.py` — Version bumped to `0.7.0`.
